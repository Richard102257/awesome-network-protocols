# 协议条目规范

每个完整教学条目应包含：

1. **身份信息** — 稳定 ID、名称、全称、状态和标准组织。
2. **用途** — 用一句话说明它解决的问题。
3. **原理** — 用清晰语言解释核心机制。
4. **位置** — 网络层、依赖、承载内容和常见标识符。
5. **消息流程** — 按时间顺序描述步骤及失败路径。
6. **报文结构** — 关键字段及其含义。
7. **安全性** — 已提供和未提供的保证、常见误用及替代方案。
8. **观察方法** — 抓包样例和分析器过滤表达式。
9. **实现** — 持续维护的开源客户端、服务端或库。
10. **来源** — 先列规范标准，再列高质量学习资料。

图表必须包含文本说明，并且在关闭动画或无法区分颜色时仍可理解。
