# 协议目录

规范目录位于 [data/protocols.json](../../data/protocols.json)，本页提供适合阅读的分类入口。

## 应用服务

- [HTTP](https://www.rfc-editor.org/rfc/rfc9110) — Web 与 API 请求响应通信。
- [DNS](https://www.rfc-editor.org/rfc/rfc1034) — 分布式命名与记录查询。
- [DHCP](https://www.rfc-editor.org/rfc/rfc2131) — 自动地址与网络配置。
- [SMTP](https://www.rfc-editor.org/rfc/rfc5321) — 邮件提交与转发。
- [SSH](https://www.rfc-editor.org/rfc/rfc4251) — 加密远程访问与隧道。
- [MQTT](https://docs.oasis-open.org/mqtt/mqtt/v5.0/mqtt-v5.0.html) — 轻量发布订阅消息。
- [RTP](https://www.rfc-editor.org/rfc/rfc3550) — 实时媒体样本传输。

## 传输与网络互联

- [TCP](https://www.rfc-editor.org/rfc/rfc9293) — 可靠、有序的字节流。
- [UDP](https://www.rfc-editor.org/rfc/rfc768) — 开销较低的独立数据报。
- [QUIC](https://www.rfc-editor.org/rfc/rfc9000) — 基于 UDP 的加密、可靠、多路复用传输。
- [IPv4](https://www.rfc-editor.org/rfc/rfc791) — 使用 32 位地址寻址与转发。
- [IPv6](https://www.rfc-editor.org/rfc/rfc8200) — 使用 128 位地址寻址与转发。
- [ICMP](https://www.rfc-editor.org/rfc/rfc792) — 网络控制与错误报告。

## 路由与局域网

- [BGP](https://www.rfc-editor.org/rfc/rfc4271) — 自治系统之间基于策略的路由。
- [OSPF](https://www.rfc-editor.org/rfc/rfc2328) — 组织内部的链路状态路由。
- [Ethernet](https://standards.ieee.org/ieee/802.3/10422/) — 有线局域网帧传输。
- [Wi-Fi](https://standards.ieee.org/ieee/802.11/10548/) — 无线局域网帧传输。
- [ARP](https://www.rfc-editor.org/rfc/rfc826) — IPv4 本地下一跳解析。

## 安全与专用网络

- [TLS](https://www.rfc-editor.org/rfc/rfc8446) — 经过认证的应用会话加密。
- [Modbus TCP](https://www.modbus.org/specs.php) — 工业寄存器与线圈访问。
