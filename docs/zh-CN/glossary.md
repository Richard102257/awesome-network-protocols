# 术语表

| English | 简体中文 | 说明 |
|---|---|---|
| packet | 分组 | 网络层传输单元；上下文明确时也可称数据包 |
| frame | 帧 | 数据链路层传输单元 |
| datagram | 数据报 | 独立、面向消息的传输单元 |
| payload | 载荷 | 去除当前层控制字段后的内容 |
| peer | 对等方 | 同一协议会话中的另一通信方 |
| route | 路由 | 到达目标网络的路径或路径记录 |
| resolver | 解析器 | 代表客户端执行名称查询的组件 |
| handshake | 握手 | 建立通信状态或协商参数的交换过程 |
